# Donor Provenance Policy

Potential conceptual donors:
- StillDone
- ChangeMesh
- ContextSeal
- Basebreak
- Codex Control Tower
- ZeroKit AI Control Plane
- Universal Agent OS and editions

## Default classification

`CONCEPT_ONLY`

Prior projects are sources of lessons, not templates to clone.

Useful conceptual DNA may include:
- independent read-back
- revocable truth
- bounded authority
- provider-success/local-persistence failure recovery
- evidence honesty
- deterministic facts before model prose
- independent verification

## Competition-defining logic

Default:
- `CONCEPT_ONLY`
or
- `CLEAN_ROOM_REIMPLEMENTED`

Do not import donor names, terminology, file structure or architecture merely because they existed before.

## Actual code reuse

No source reuse is allowed without a provenance record containing:
- donor repository
- immutable source SHA
- license
- source path
- target path
- exact transformation
- tests
- reuse class
- introduction commit

If provenance is incomplete, reuse is blocked.
